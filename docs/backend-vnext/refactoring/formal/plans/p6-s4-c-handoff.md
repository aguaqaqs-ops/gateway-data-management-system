## Product boundary

- `gateway-compute-core/sql_replay.rs` is the sole literal, DDL, DML, statement-length and batching implementation. It uses the full persisted key, preserves manifest column and primary-key declaration order for DDL, and orders DML key and persisted column names by UTF8 bytes. It keeps the original 256-row D/U windows, a 4 MiB complete-statement split, and a 200 MiB cap in each C rendering path. A checked statement cursor emits at most 1 MiB per call; text, binary and BIT values are encoded from retained raw values while emitting, with 64 KiB cancellation/deadline checks during long literals.
- The PyO3 SQL adapter renders generic ChangeSet and schema from structured JSON under the real explicit kernel operation, detaches the GIL for Rust work, and returns bytes with the existing public outcome/capability/digest and schema facade shapes. The generic facade retains its structural ChangeSet input; it does not synthesize a canonical storage stream.
- `NativeStorageTableHandle.render(decision)` opens a new render phase under the same Python M after B's prepare reconciliation and `apply_decision`. Rust accounts for typed row conversion, prepared literals, fragment descriptors, the current 1 MiB Vec, and the PyBytes copy before allocation. The Python reservation owns already exported bytes until the operation scope ends. The native cursor, Arrow table and input lease close before that result reservation is returned; a closed handle clears its task and Arrow references even while the scope callback retains the handle object. The table cursor checks a cumulative 200 MiB cap across D/U/I, separate from M exhaustion.
- Storage Projection's schema facade passes the frozen 200 MiB SQL cap to Rust and separately reserves a conservative per-declaration conversion/output envelope before JSON and FFI copies. A direct structured schema is permitted even when its output exceeds four times the JSON payload. Its context identity flows through Snapshot Materialization and Storage Projection re-exports, without a reverse Projection-to-Mutation import.
- The old Python SQL literal/DDL/DML/statement batching implementation and its private limit probes were removed. B's temporary `architecture_baseline.native` entry is deleted because C's generic renderer is a real consumer; B's `storage` entry remains until D wires Submit.
