- P6-S6 的既定性能门槛、真实数据与最终门禁不因 P7-D01 自动变更；P7 实施入口复核 P6 正式退出及其最终 N/M、资源证据。
- 本轮试运行可重建，仍使用单一 control DB 基线 schema，不提前建设前向 migration。首次承诺保留部署数据前，按 AGENTS 引入必要的升级和备份恢复机制；“可从源重建”不等于可恢复原操作 ID、审核记录或资源曲线。
- P8/P9 不再被理解为必须建设 legacy 双轨或为当前试运行延期基本恢复能力。P7 完成受控试运行准备；实际部署、扩大使用和必须保留数据后的生产要求另行安排。长期容量校准不自动等于 P8 已启动。
