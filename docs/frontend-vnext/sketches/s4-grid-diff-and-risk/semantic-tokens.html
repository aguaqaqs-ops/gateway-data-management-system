规则

  1. 数据行里颜色只表示风险：行底色 + 左侧色条；高 / 中高用红、橙暖色，中低用天蓝、低用绿，未知用淡紫；无风险保持白底。
  2. 变更类型是中性的：+ − 符号或更新前后连线占同一符号位，配文字、删除线和加粗，文字颜色跟随该行风险等级（无风险行为深灰）。
  3. 改动单元格用同色系加深底色标出，两行同列对齐；新值加粗。
  4. 风险等级文字不进数据行，在信息行图例（兼计数）与悬停提示中给出；导航徽章与变更分布条同样“有风险显示风险色，否则中性”。
  5. 文字与底色对比度不低于 4.5:1，包括改动格里的旧值（#3F4752）。
