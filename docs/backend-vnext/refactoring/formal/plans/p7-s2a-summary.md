# P7 S2a 阶段总结

S2a 在单处理组内提供固定编号的多 worker：同规格 W=K、每进程单 executor；固定身份和进程生命周期锁防止同编号重叠，随机 lease token 与原事务/CAS 保持领取代际和结果保护。重启只恢复本实例遗留任务，其他实例不接管；任务级人工处置和退避不会阻止健康任务，损坏或不合法 owner 仍拒启。Submit 的原占用、冻结提交和 UNKNOWN 原 key 语义未放宽。

共享缓存沿用原子发布和保护，允许有界重复计算。Repository Service 对同库实际 CLI 访问复用许可，读和导入互斥、不同库可并发，确认执行者退出才释放；专用 busy 有有限等待，已暴露流不重放。统计返回时间窗内多实例及截断标志，不将采样视为在线注册。固定服务部署核实实例、镜像和资源；维护接口关闭新受理并等待在途，运维命令以 TERM 和实际进程/cgroup 退出区分 worker 停止与整组静止，队列、保护和原有时间语义保留。
