## 2. 资源边界的适用性

设计所列 64 GiB 总内存、约 63 GiB available、约 215 GiB 磁盘只是启动前观测，须由实际启动检查更新；它们不能证明四路峰值一定落在预算内。52 GiB RSS 与 8 GiB 可用内存是两种独立停止信号，前者可能重复计入共享页，后者还受节点其他内存使用影响；不应将二者互相换算后删掉一项。

以固定停止边界探索真实资源、触限即结束的设计合理，不要求先承诺完整生成能在 4 小时内完成。实际脚本是否覆盖完整诊断阶段、是否在达到阈值后及时停止并回收本次进程、是否将非 SQL 成员核验纳入成功判定，留待启动材料核对；本报告不提前认可实现。
